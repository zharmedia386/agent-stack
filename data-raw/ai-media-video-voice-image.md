#### Comfy-Org/ComfyUI

- Link: [github](https://github.com/Comfy-Org/ComfyUI) · [homepage](https://www.comfy.org/)
- ⭐ 147.4k · Python
- <b>What:</b> Local app where you build image/video/audio generation pipelines by wiring nodes in a graph. Supports Stable Diffusion, Flux, video models and more, and exposes an API so workflows can be run from code.
- <b>How to use:</b> Install PyTorch for your GPU, then:

```bash
git clone https://github.com/Comfy-Org/ComfyUI
cd ComfyUI
pip install -r requirements.txt
python main.py   # open http://127.0.0.1:8188
```

- <b>Reach for it when:</b> You want full control over a local diffusion pipeline, or need to share/reuse a workflow as a JSON graph.

#### debpalash/VoiceStudio

- Link: [github](https://github.com/debpalash/VoiceStudio) · [homepage](https://voicestudio.sh)
- ⭐ 113.1k · Python
- <b>What:</b> Desktop app for voice cloning, voice design, video dubbing, dictation, transcription and audiobook creation, all running on your own machine.

```bash
# macOS / Linux
curl -fsSL https://voicestudio.sh/install | sh

brew tap debpalash/tap
brew install --cask debpalash/tap/voicestudio
```

- <b>Reach for it when:</b> You need TTS, voice cloning or dubbing without paying per character or sending audio to a cloud.

#### jamiepine/voicebox

- Link: [github](https://github.com/jamiepine/voicebox) · [homepage](https://voicebox.sh)
- ⭐ 61.2k · Python
- <b>What:</b> Local voice studio that covers both speech output (like ElevenLabs) and dictation (like WisprFlow). Eight TTS engines (Qwen3-TTS, Chatterbox, Kokoro and others), zero-shot voice cloning, 23 languages, audio effects, a multi-track timeline for podcasts and stories, plus a REST API and MCP server so agents can speak in a voice you cloned. Built with Tauri.
- <b>How to use:</b> Download the DMG (macOS) or MSI (Windows) from [voicebox.sh](http://voicebox.sh), or run it from the repo with Docker. Linux needs a build from source.

```bash
git clone https://github.com/jamiepine/voicebox
cd voicebox
docker compose up
```

- <b>Reach for it when:</b> You want cloning, TTS and dictation in one offline app, or want your coding agent to talk back in your own voice.

#### OpenBMB/VoxCPM

- Link: [github](https://github.com/OpenBMB/VoxCPM) · [homepage](https://voxcpm.com)
- ⭐ 42.9k · Python
- <b>What:</b> Open TTS model that generates continuous speech without discrete audio tokens. VoxCPM2 is 2B parameters, covers 30 languages plus several Chinese dialects, can design a new voice from a text description, clone a voice from a short clip, and outputs 48kHz audio. Apache-2.0, commercial use allowed.
- <b>How to use:</b> Needs Python 3.10-3.12, PyTorch 2.5+ and CUDA 12+:

```py
# pip install voxcpm
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)
wav = model.generate(text="Hello from VoxCPM2.", cfg_value=2.0, inference_timesteps=10)
sf.write("demo.wav", wav, model.tts_model.sample_rate)
```

- <b>Reach for it when:</b> You need a self-hosted multilingual TTS or voice-cloning model to call from your own code.
