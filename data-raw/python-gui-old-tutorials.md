#### TomSchimansky/CustomTkinter

- [github](https://github.com/TomSchimansky/CustomTkinter) · ⭐ 13.6k · Python
- <b>What:</b> Drop-in Tkinter widgets with light/dark themes and rounded, modern styling.
- <b>How:</b> <code>pip install customtkinter</code>, then use <code>customtkinter.CTk()</code> and <code>CTkButton</code> instead of the plain Tk classes.

#### ParthJadhav/Tkinter-Designer

- <b>What:</b> Reads a Figma file through the Figma API and generates a Tkinter GUI from it.
- <b>How:</b> Design in Figma, paste your Figma token and file URL into the Tkinter Designer app, and it writes the Python code plus assets.
