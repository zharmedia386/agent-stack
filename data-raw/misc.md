#### anefzaoui/misterdownloadmanager

- Link: [github](https://github.com/anefzaoui/misterdownloadmanager) · [site](https://misterdownloadmanager.com)
- ⭐ 17.8k · Rust
- <b>What:</b> Open-source (GPL) download manager written from scratch in Rust, styled as an IDM alternative. It splits files into parallel parts, resumes broken downloads, grabs downloads from browsers via an extension, and handles videos, image galleries and torrents. Windows and Linux builds, macOS builds are marked experimental.
- <b>How to use:</b>

```bash
winget install AhmedNefzaoui.MisterDownloadManager
```

On Linux or macOS, pick the <code>.deb</code>, <code>.rpm</code>, <code>.AppImage</code> or <code>.dmg</code> from the latest GitHub release (see the Download section of the README).

- <b>Reach for it when:</b> you want a free desktop download accelerator with browser integration and torrent support.

#### DhvanilPatel/swarm-cursors

- Link: [github](https://github.com/DhvanilPatel/swarm-cursors) · [Chrome Web Store](https://chromewebstore.google.com/detail/swarm-rebuild/diaeaocnhdhbknkbfbnkjikfcgokainm)
- ⭐ 3.7k · JavaScript
- <b>What:</b> Chrome extension (Swarm Rebuild) that blanks any page, then has a swarm of multiplayer-style cursors draw it back: boxes, typed text, lines, guides and duplicates. It is a tribute to Joel Califa's Swarm site and reuses parts of its animation engine. The repo has no license yet, so check before reusing code.
- <b>How to use:</b> Install it from the Chrome Web Store, or clone the repo, turn on Developer mode at <code>chrome://extensions</code>, click Load unpacked and choose the <code>swarm-rebuild/</code> folder. Then click the toolbar icon or press Alt+Shift+S on a page.
- <b>Reach for it when:</b> you want a screen-recording gimmick, or a reference for snapshotting a live DOM and animating it.
