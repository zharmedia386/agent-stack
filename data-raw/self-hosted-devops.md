```bash
docker run -d -p 9443:9443 --name portainer --restart=always \

```

#### moghtech/komodo

- Link: [github](https://github.com/moghtech/komodo) · [komo.do](https://komo.do)
- ⭐ 13k · Rust
- <b>What:</b> Build and deploy tool for many servers: a Core web app plus a Periphery agent on each server. Manages compose stacks, builds, env vars and server stats, with GitOps-style syncs.
- <b>How to use:</b>
  1. Follow the setup guide on [komo.do](https://komo.do): download its compose file and env file and run Core with <code>docker compose up -d</code>.
  2. Install Periphery on each server you want to manage ([periphery setup](https://github.com/moghtech/komodo/blob/main/scripts/readme.md)).
  3. Add the servers in the UI and deploy stacks. A demo is at [demo.komo.do](http://demo.komo.do) (demo/demo).
- <b>Reach for it when:</b> you run compose stacks across several servers and want one dashboard.
