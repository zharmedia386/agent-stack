## Browser automation for agents

#### browser-use/browser-use

- Link: [github](https://github.com/browser-use/browser-use) · [browser-use.com](https://browser-use.com)
- ⭐ 121.4k · Python
- <b>What:</b> Open-source browser agent. Since 1.0 the model writes Python against raw CDP in a persistent REPL. Comes as a Python library, a CLI, and a paid cloud (stealth browsers + hosted agent API).
- <b>How to use:</b> pin the exact version, releases move fast.

```bash
uv add 'browser-use==1.0.6'
export BROWSER_USE_API_KEY=bu_...
```

```py
from browser_use import Agent

result = Agent('Find the number of stars of the browser-use repo').run_sync()
print(result.final_result())
```

- <b>Reach for it when:</b> you want an LLM to complete a multi-step task on real websites from Python.

```json
  }
}
```

#### vercel-labs/agent-browser
