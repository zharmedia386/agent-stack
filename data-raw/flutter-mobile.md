#### lynx-family/lynx

- Link: [github](https://github.com/lynx-family/lynx) · [lynxjs.org](https://lynxjs.org)
- ⭐ 15.3k · C++
- <b>What:</b> Cross-platform UI framework from ByteDance (used in TikTok). You write ReactLynx (React-style) with CSS, it renders native views on Android/iOS and also web, with a dual-thread engine for smooth UI.
- <b>How to use:</b>

```bash
npm create rspeedy@latest   # scaffold a ReactLynx project
npm install && npm run dev  # scan the QR code with the Lynx Explorer app to preview
```

- <b>Reach for it when:</b> you want native mobile apps from web skills, as an alternative to React Native.

#### imaNNeo/fl\_chart

- Link: [github](https://github.com/imaNNeo/fl_chart) · [flchart.dev](https://flchart.dev)
- ⭐ 7.6k · Dart
- <b>What:</b> The go-to Flutter chart library: line, bar, pie, scatter, radar and candlestick charts with touch, tooltips and animations.
- <b>How to use:</b>

```dart
// flutter pub add fl_chart
LineChart(
  LineChartData(
    lineBarsData: [
      LineChartBarData(spots: const [FlSpot(0, 1), FlSpot(1, 3), FlSpot(2, 2)]),
    ],
  ),
)
```

- <b>Reach for it when:</b> a Flutter app needs charts or dashboards.
