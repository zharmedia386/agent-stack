- <b>What:</b> "Blind LLM Agents": defensive CLI + MCP that hardens release builds (JS/TS, Electron ASAR, WASM, Python, native binaries, GGUF…) so AI reverse-engineering agents waste effort or hallucinate.
- <b>How to use:</b>

```bash
npx bla-agents harden .           # writes a hardened mirror to .bla-hardened/
npx bla-agents harden . --apply   # replace the build output
npx bla-agents harden . --restore # undo
npx bla-agents setup              # MCP / agent setup
```

- <b>Reach for it when:</b> shipping client-side code you want to make harder to reverse-engineer with LLMs.
