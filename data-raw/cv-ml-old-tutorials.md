### YOLO & object tracking

#### ultralytics/yolov5

- [github](https://github.com/ultralytics/yolov5) · [docs](https://docs.ultralytics.com/yolov5/) · ⭐ 58.3k · Python
- <b>What:</b> PyTorch YOLOv5 for detection, instance segmentation and classification, with training and export (ONNX, TensorRT, CoreML, TFLite).
- <b>How:</b> Clone, <code>pip install -r requirements.txt</code>, then <code>python detect.py --weights yolov5s.pt --source 0</code> (webcam) or <code>train.py</code> for custom data. Newer projects usually use the <code>ultralytics</code> package instead.

#### theAIGuysCode/yolov4-deepsort

- [github](https://github.com/theAIGuysCode/yolov4-deepsort) · ⭐ 1.4k · Python
- <b>What:</b> Multi-object tracking: YOLOv4 detections fed into DeepSORT, in TensorFlow 2.
- <b>How:</b> Download YOLOv4 weights, convert them with <code>save_model.py</code>, then run <code>object_tracker.py</code> on a video.

#### wei-tim/YOWO

- [github](https://github.com/wei-tim/YOWO) · ⭐ 914 · Python
- <b>What:</b> Research code for YOWO, a single CNN that localizes and classifies human actions in video in real time (UCF101-24, J-HMDB, AVA).
- <b>How:</b> Prepare a dataset and pretrained backbones as in the README, then train/evaluate with the provided scripts.

#### theAIGuysCode/yolov4-custom-functions

- [github](https://github.com/theAIGuysCode/yolov4-custom-functions) · ⭐ 609 · Python
- <b>What:</b> Extends the TF YOLOv4 repo with object counting, per-class counts, cropping detections, license-plate OCR and info printing.
- <b>How:</b> Same setup as tensorflow-yolov4-tflite, then enable features via flags on <code>detect.py</code> / <code>detect_video.py</code> (see README).

#### theAIGuysCode/Object-Detection-API

- [github](https://github.com/theAIGuysCode/Object-Detection-API) · ⭐ 346 · Python
- <b>What:</b> YOLOv3 (TensorFlow) wrapped in a Flask API that returns detections as JSON or as an annotated image.
- <b>How:</b> Load weights, start the Flask app, POST an image to the detection endpoint.

#### theAIGuysCode/tensorflow-yolov4-tflite
